# Enhanced Input 可测性约束

**编写测试脚本时必须同时使用 `ue-autotesttools-core`。** 只有在实际编写或维护测试时，才按需读取 [Input 测试接口参考](../../references/input-testing-api.md)；设计业务实现时不要加载接口细节。

## 约束

- 以 `UInputAction` 表达业务语义，并让处理后的动作值可读取；物理键位只用于验证映射兼容性。
- 固定每个动作的值类型。Boolean、Axis1D、Axis2D、Axis3D 不做隐式互转，数值分量必须有限。
- 显式绑定 PIE World、玩家控制器和受控 Pawn；按名称解析时要求精确、唯一，不依赖枚举顺序。
- 一次性输入按处理帧观察；跨帧输入必须拥有独立句柄，并在成功、异常、取消和超时路径上释放。
- 物理输入必须跟踪所有接收过注入的控制器，结束时释放按键并清空状态。
- 输入清理必须幂等、可重试；先停止语义连续输入，再清理物理按键，不能让前一个失败阻止其他资源清理。

## 可测类别

- InputAction 的对象、资源路径和唯一绑定名解析。
- Boolean、Axis1D、Axis2D、Axis3D 的一次性注入与处理后值。
- 连续动作的按下、保持、释放、取消和多句柄所有权。
- 控制器、Pawn、World 隔离，以及按键、轴、WASD、跳跃等物理兼容行为。

## 反模式

- 用 `W`、`SpaceBar` 等具体键位代表移动、跳跃等业务契约。
- 依赖固定延时后猜测输入已处理，或只检查“注入成功”而不观察动作值或业务结果。
- 复用无所有权的全局按下状态，或者只在成功路径释放输入。
- 把布尔当数值轴、接受非有限值，或在绑定名存在歧义时任取一个动作。
